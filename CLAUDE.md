# TeleFi

Telegram as a two-way control surface for scripts, CI and agents. `deploymentTier: pre-traffic`.

This repo is public, and it is the only home of the code. Everything committed here is published.

- Test gate: `python -m pytest -q`.
- Commit with the GitHub no-reply address, never a personal one.
- Keep out of this repo: names of private projects, local paths, personal data, internal plans and decision logs.
  Sample data uses neutral names (`research`, `assistant`, `builder`, `newsdesk`).
- Internal docs live outside this repo, in the owner's private docs under `telefi/`.
- A plain tag (`v*`) publishes to PyPI, so tagging is a release and needs the owner's go.
